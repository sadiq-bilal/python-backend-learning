
# 🐍 Learning Python for Backend Development — 30 Days

A **30-day structured learning journey** to learn Python fundamentals and gradually move toward **backend development**.

This repository contains my daily learning notes, practice programs, exercises, and projects while completing a 30-day Python Backend Development course.

## 🎯 Goal

The goal of this course is to build a strong foundation in **Python** and understand the core concepts required to start developing backend applications using **APIs, HTTP, REST, FastAPI, and asynchronous Python**.

By the end of 30 days, I aim to be able to:

* Write clean and structured Python code
* Work with Python data structures
* Use functions, modules, and packages
* Handle files, JSON, and errors
* Understand Object-Oriented Programming
* Create and manage virtual environments
* Use `pip` and Python packages
* Understand iterators, generators, and decorators
* Work with type hints
* Understand HTTP and REST APIs
* Write asynchronous Python code
* Build a basic backend API using FastAPI
* Complete a backend-focused Python project

# 📅 30-Day Course Roadmap

| Days      | Theme                                      | Topics                                                         |
| --------- | ------------------------------------------ | -------------------------------------------------------------- |
| **1–3**   | 🐍 Python Foundations                      | Setup, types, operators, strings                               |
| **4–6**   | 🔄 Control Flow & Collections              | Conditions, loops, lists, tuples, sets                         |
| **7–9**   | 📦 Dictionaries & Data Handling            | Dictionaries, data handling, comprehensions                    |
| **10–12** | ⚙️ Functions & Code Organisation           | Functions, parameters, return values, code organisation        |
| **13–15** | 📁 Python Modules & Files                  | Modules, packages, errors, files, JSON                         |
| **16–18** | 🏗️ Object-Oriented Python                 | Classes, objects, inheritance, encapsulation, polymorphism     |
| **19–21** | 🛠️ Python Environment & Project Structure | pip, virtual environments, standard library, project structure |
| **22–24** | 🚀 Advanced Python Concepts                | Iterators, generators, decorators, type hints                  |
| **25–27** | 🌐 Async & Web Fundamentals                | Async Python, HTTP, REST fundamentals                          |
| **28–30** | ⚡ FastAPI & Final Project                  | FastAPI introduction, final project, final assessment          |
